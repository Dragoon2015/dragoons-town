# Dragoon's Town

Build a town of businesses, collect and upgrade homes and vehicles, complete civic projects, and prestige for lasting income bonuses.

This repository is intended for Android test downloads and release notes. The development project is maintained separately.

## First Android test build

Version: **0.13.0-debug**. APK filename: `dragoons-town-0.13.0-debug.apk` (approximately 4.12 MB).

Android requirement: **Android 7.0 or newer**, with an up-to-date Android System WebView. Android 13 is within the supported OS range; physical-device testing is still pending.

Open this repository's **Releases** section and download the APK from the release's **Assets** list. Do not download the automatically generated source archive to install the game.

1. Copy/download the APK onto your Android device.
2. Open it with your file manager. If Android asks, allow that file manager to install apps from this source.
3. Install and open **Dragoon's Town**.
4. For later updates, install the new APK over the old one. Do not uninstall first if you want to keep local progress. Updates must use the same package ID and signing key.

## Saves and testing

Progress is stored on your device. Export a backup before uninstalling, clearing app data, or switching builds. To bring your website progress into Android, export the JSON save on the website and import it in the app.

This is an early debug build, not a Google Play release. The APK was compiled and its signature verified, but Android device behavior still needs testing. There are no real-money purchases or ads in this build. Gameplay can run offline.

Try bank tapping, business upgrades, town navigation, home/vehicle purchases, background earnings, save export/import, and restarting the app. Report your device, Android version, what happened and steps to reproduce it. Share save files only if you intend to share your game progress. Never post passwords or personal account information.

The app contains bundled web assets; sharing the APK also makes those assets inspectable. Keeping the development repository private does not make the installed app's code secret.
